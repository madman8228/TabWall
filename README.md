# TabWall

TabWall 是一个轻量、以本地存储为优先的浏览器标签页整理工具。

它可以把当前窗口中暂时不想继续打开的网页收纳起来，整理成清晰的标签墙，需要时再恢复到浏览器中。

## 核心功能

- 一键收纳当前窗口中的网页标签页
- 通过右键菜单保存单个网页
- 保留网页标题、网址、图标、原始顺序和保存时间
- 支持恢复单个页面或全部页面到浏览器
- 全部恢复采用延迟加载，选择页面时才真正打开网站
- 支持按原始顺序查看，或按网站分组查看
- 支持拖拽调整标签顺序
- 可设置每行显示 10–60 个标签
- 普通窗口与 InPrivate 窗口的数据相互隔离
- 支持中文和英文界面
- 数据仅保存在本地，无账号、无云同步、无广告、无分析服务

## 使用方式

1. 在浏览器中安装并固定 TabWall 图标。
2. 打开需要暂时收纳的网页。
3. 点击工具栏中的 TabWall 图标，当前窗口的网页会被保存到标签墙中。
4. 在 TabWall 页面中，可以按原始顺序或网站分组查看。
5. 点击标签卡片即可恢复单个页面，点击“Restore all”可以恢复全部页面。

也可以在网页上点击右键，选择“Save current page to TabWall”，只保存当前页面。

## 数据与隐私

TabWall 只为实现标签页收纳、整理和恢复功能而处理以下信息：

- 网页标题
- 网页网址
- 网页图标地址
- 标签顺序
- 保存时间和访问时间
- TabWall 的显示偏好

这些数据保存在浏览器本地。TabWall 不会将数据上传到服务器，不要求登录，也不提供云端同步。

详细说明请查看 [隐私政策](privacy-policy.html)。

## 权限说明

TabWall 使用的权限均服务于核心功能：

- `tabs`：读取当前标签页信息，并创建恢复页面
- `storage`：保存本地数据和用户偏好
- `contextMenus`：提供右键保存当前页面功能

## 本地安装

TabWall 是一个 Manifest V3 浏览器扩展，可用于支持 Chromium 扩展的桌面浏览器。

1. 打开浏览器的扩展管理页面。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展”。
4. 选择包含 `manifest.json` 的项目目录。

```

lazy-tab.html/js    # 延迟恢复页面
icons/              # 扩展图标与 Logo
_locales/           # 中英文界面文案
tests/              # 单元测试与集成测试
```

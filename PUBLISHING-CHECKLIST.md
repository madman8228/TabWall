# TabWall publishing checklist

- [ ] Confirm the final version in `manifest.json`.
- [ ] Test normal browsing, right-click save, individual restore, Restore all, Clear all, reorder, domain view, and InPrivate mode.
- [ ] Host `privacy-policy.html` at a public HTTPS URL.
- [ ] Capture store screenshots at 1280x800 or 640x480.
- [ ] Prepare a 440x280 promotional tile for Edge Add-ons.
- [ ] Create the Edge Partner Center developer account.
- [ ] Create the Chrome Web Store developer account.
- [ ] Build the upload ZIP with `manifest.json` at the ZIP root.
- [ ] Upload the ZIP and complete listing, privacy, distribution, and certification fields.
- [ ] Submit for review.
